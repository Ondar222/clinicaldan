# Документация по разделу «Косметология»

## Обзор

Раздел косметологии реализован как полноценный коммерческий и SEO-раздел с полной интеграцией с прайсом, врачами и оборудованием.

## Структура URL

```
/services/cosmetology                          - Главная страница отделения
/services/cosmetology/{category}               - Страница категории
/services/cosmetology/{category}/{service}     - Страница услуги
```

## Категории косметологии

Раздел включает 8 категорий:

1. **Инъекционная косметология** (`/services/cosmetology/injection`)
   - Ботулинотерапия, контурная пластика, мезотерапия, плазмотерапия

2. **Аппаратная косметология** (`/services/cosmetology/apparatus`)
   - Лазер, RF, фотоомоложение, SMAS-лифтинг

3. **Диагностика кожи** (`/services/cosmetology/skin-diagnostics`)
   - Анализ кожи, подбор ухода, диагностика

4. **Пилинги** (`/services/cosmetology/peelings`)
   - Химические пилинги различной глубины

5. **Чистки лица** (`/services/cosmetology/cleaning`)
   - УЗ-чистка, механическая, комбинированная

6. **Уходовые процедуры** (`/services/cosmetology/care`)
   - Маски, массаж, увлажнение, омоложение

7. **Коррекция фигуры** (`/services/cosmetology/body`)
   - Липолиз, кавитация, криолиполиз, массаж

8. **Сосудистая эстетика** (`/services/cosmetology/vascular`)
   - Удаление сосудов, лазерное лечение купероза

## Интеграция с данными

### Услуги
Услуги косметологии автоматически подтягиваются из `archimedService.getServices()` и фильтруются по ключевым словам категорий.

### Врачи
Врачи-косметологи фильтруются по типу: `type.includes('космет')` или `type.includes('дерматовенеролог')`.

### Цены
Цены синхронизированы с прайсом через `service.base_cost` и `service.cito_cost`.

## SEO

### Мета-теги
Каждая страница имеет уникальные meta-теги через `SeoHead` компонент:
- `title` - уникальное название
- `description` - уникальное описание
- `canonical` - канонический URL
- `og:*` - Open Graph теги

### Schema.org
Интегрирован `SchemaOrg` компонент с поддержкой:
- `MedicalClinic` для главной страницы
- `MedicalWebPage` для страниц услуг
- `BreadcrumbList` для хлебных крошек

### Sitemap
Все URL косметологии автоматически включаются в sitemap через `/api/sitemap.xml`:
- `/services/cosmetology`
- `/services/cosmetology/{category}`
- `/services/cosmetology/{category}/{service}`

## Для контент-менеджера

### Заполнение услуг

Услуги заполняются через CMS/админку. Контент-менеджер должен:

1. **Название услуги** - соответствует прайсу
2. **Описание** - краткое и полное описание процедуры
3. **Цена** - берется из pricelist
4. **Длительность** - в минутах
5. **Показания** - список показаний
6. **Противопоказания** - список противопоказаний
7. **Подготовка** - рекомендации перед процедурой
8. **Послеуход** - рекомендации после процедуры
9. **FAQ** - вопросы и ответы для услуги
10. **Врач** - привязка ответственного специалиста
11. **Оборудование** - привязка аппаратов (если применимо)

### Категории

Категории предварительно настроены в `src/data/cosmetology.ts`. Для добавления новой категории:

```typescript
{
  id: 'new-category',
  slug: 'new-category',
  name: 'Название категории',
  description: 'Полное описание',
  shortDescription: 'Краткое описание',
  icon: '🎨',
  keywords: ['ключ1', 'ключ2', 'ключ3'],
  order: 9,
  doctorKeywords: ['космет'],
  equipmentKeywords: ['аппарат']
}
```

### FAQ

FAQ редактируется в `src/data/cosmetology.ts`:

```typescript
export const COSMETOLOGY_FAQ: FAQItem[] = [
  {
    question: 'Вопрос',
    answer: 'Ответ',
    category: 'injection' // опционально
  }
];
```
